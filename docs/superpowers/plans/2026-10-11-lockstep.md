# Lockstep Stepping Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scrimmage drives the robot program's clock in fixed steps through a small HALSim extension. Runs then repeat exactly and can go faster than real time, with robot code unmodified.

**Architecture:** A C++ HALSim extension (`lockstep/`) pauses WPILib timing and exposes a `ScrimmageLockstep` SimDevice. `halsim_ws_client` relays that device over the existing WebSocket. On the Python side, `Bridge` gets two drivers: today's real-time loop, and a `LockstepDriver` that alternates physics steps with robot steps (`>step_seq` → `<done_seq`). Both share a sim-time `_on_tick` for the DS script, logging and viewer.

**Tech Stack:**
- Python 3.11+ (dev venv: `.venv`, Python 3.14), asyncio, `websockets` 17, MuJoCo 3
- RobotPy 2026.2.2
- C++20 against the HAL C API from `robotpy-native-wpihal`; CMake plus scikit-build-core

**Spec:** `docs/superpowers/specs/2026-10-11-lockstep-design.md`

## Global Constraints

- Linux only. WPILib/RobotPy 2026 (`>=2026.2,<2027`).
- Robot code stays unmodified. Lockstep is enabled only by loading the extension (`--scrimmage-lockstep` for RobotPy).
- The extension calls only the HAL C API (functions declared `extern "C"` in `hal/*.h`, plus the header-inline helpers built on them).
- SimDevice name `ScrimmageLockstep`. Values: `engage` (bool, input), `step_us` (long, input), `step_seq` (long, input), `engaged` (bool, output), `done_seq` (long, output). On the wire `>` = into robot code, `<` = out of robot code.
- Default lockstep step 5 ms (`DEFAULT_STEP = 0.005`). It must be a whole multiple of the physics timestep.
- Extension grace period 5 s (env `SCRIMMAGE_LOCKSTEP_GRACE_S`). Watchdog 2 s.
- Scrimmage: lockstep detection window 2 s; the "waiting on robot program" warning first after 2 s, then every 10 s.
- `--speed` is a positive factor (default `1.0`) or `max`. Any value other than `1.0` without lockstep is an error (exit code 2).
- Existing real-time behavior and the existing e2e tests must keep passing unchanged.
- Run everything with the project venv: `.venv/bin/python -m pytest ...`, `.venv/bin/pip ...`.

## Review Focus

1. **Extension loaded but Scrimmage never runs.** The robot must run in real time after the grace period, not hang. Pinned in Task 1 (`test_grace_period_releases_clock_without_scrimmage`).
2. **Scrimmage killed or stalled mid-run.** The watchdog must hand the clock back, and a later step request must take it again. Pinned in Task 1 (`test_watchdog_releases_clock_and_steps_reengage`).
3. **The robot program crashes or disconnects while Scrimmage waits for an ack.** The bridge must go back to idle and serve the next robot program. Pinned in Task 4 (`test_robot_disconnect_mid_step_returns_to_idle`).
4. **Scrimmage restarted while the robot program keeps running.** Step numbering must continue from the robot's `done_seq`, or the bridge waits forever. Pinned in Task 4 (`test_lockstep_continues_from_robot_done_seq`).
5. **Bad `--speed` / `--step` values** (`0`, `fast`, a step that isn't a multiple of the timestep) must give a clear startup error, not a traceback or a silent hang. Pinned in Task 5 (`test_cli_rejects_bad_speed_and_step`).

```python
import hal
import wpilib

_D = hal.SimDevice.Direction


class MyRobot(wpilib.TimedRobot):
    def robotInit(self):
        # "Probe" has no "Type:" prefix, so the ws client relays it as {"type": "SimDevice", "device": "Probe"}
        self.dev = hal.SimDevice("Probe")
        self.init_us = self.dev.createLong("init_us", _D.kOutput, wpilib.RobotController.getFPGATime())
        self.loop_us = self.dev.createLong("loop_us", _D.kOutput, 0)
        self.loops = self.dev.createLong("loops", _D.kOutput, 0)
        self.fast = self.dev.createLong("fast", _D.kOutput, 0)
        self.addPeriodic(self._fast, 0.005)

    def _fast(self):
        self.fast.set(self.fast.get() + 1)

    def robotPeriodic(self):
        # loop_us first: by the time scrimmage sees `loops` change, this loop's clock reading is already there
        self.loop_us.set(wpilib.RobotController.getFPGATime())
        self.loops.set(self.loops.get() + 1)
```

```python
"""The scrimmage_lockstep HALSim extension against a real RobotPy program, with this test playing scrimmage.

Needs `pip install ./lockstep` (plus robotpy[sim] and robotpy-halsim-ws). Each test starts a robot process (~3 s).
"""

import asyncio
import os
import subprocess
import sys
import time
from pathlib import Path

import pytest
import websockets

pytest.importorskip("wpilib")
pytest.importorskip("halsim_ws")
pytest.importorskip("scrimmage_lockstep")

from scrimmage.protocol import HalState, frame  # noqa: E402

ROOT = Path(__file__).resolve().parents[1]
PORT = 3318
DEV = ("SimDevice", "ScrimmageLockstep")
PROBE = ("SimDevice", "Probe")


class FakeSim:
    """A minimal stand-in for scrimmage: a WebSocket server that records what the robot program reports."""

    def __init__(self):
        self.hal = HalState()
        self.ws = None
        self.changed = asyncio.Event()
        self.connected = asyncio.Event()

    async def handler(self, ws):
        self.ws = ws
        self.connected.set()
        try:
            async for raw in ws:
                self.hal.apply(raw)
                self.changed.set()
        except websockets.ConnectionClosed:
            pass

    def get(self, key, name, default=None):
        return self.hal.get(*key, name, default)

    async def until(self, pred, timeout):
        deadline = time.monotonic() + timeout
        while not pred():
            self.changed.clear()
            if pred():
                break
            left = deadline - time.monotonic()
            if left <= 0:
                raise AssertionError(f"timed out; devices seen: {sorted(self.hal.devices)}")
            try:
                await asyncio.wait_for(self.changed.wait(), left)
            except TimeoutError:
                pass

    async def send(self, key, data):
        await self.ws.send(frame(*key, data))

    async def engage(self, step_us=5000):
        await self.send(DEV, {">step_us": step_us, ">engage": True})
        await self.until(lambda: self.get(DEV, "<engaged") is True, 5)

    async def step(self, seq):
        await self.send(DEV, {">step_seq": seq})
        await self.until(lambda: (self.get(DEV, "<done_seq") or 0) >= seq, 5)


async def with_robot(body, env_extra=None) -> str:
    """Run `body(sim)` with a probe robot connected; returns the robot program's output."""
    sim = FakeSim()
    env = dict(os.environ, HALSIMWS_PORT=str(PORT), HALSIMWS_HOST="localhost", **(env_extra or {}))
    async with websockets.serve(sim.handler, "localhost", PORT):
        robot = subprocess.Popen(
            [sys.executable, "-m", "robotpy", "sim", "--nogui", "--ws-client", "--scrimmage-lockstep"],
            cwd=ROOT / "tests" / "lockstep_probe", env=env,
            stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True)
        try:
            await asyncio.wait_for(sim.connected.wait(), 30)
            await sim.until(lambda: DEV in sim.hal.devices and sim.get(PROBE, "<init_us") is not None, 30)
            await body(sim)
        finally:
            robot.kill()
            out = robot.communicate()[0]
    return out


def test_steps_robot_clock_and_orders_outputs():
    async def body(sim):
        await asyncio.sleep(1.0)
        assert (sim.get(PROBE, "<loops") or 0) == 0          # paused from load: no loops before engage
        await sim.engage()
        init_us = sim.get(PROBE, "<init_us")
        prev = sim.get(PROBE, "<loops") or 0
        for n in range(1, 41):                                # 40 x 5 ms = 200 ms of robot time
            await sim.step(n)
            loops = sim.get(PROBE, "<loops") or 0
            if loops != prev:
                # outputs of the loop that ran during step n arrived before done_seq = n
                elapsed = sim.get(PROBE, "<loop_us") - init_us
                assert (n - 1) * 5000 < elapsed <= n * 5000, (n, elapsed)
            prev = loops
        assert prev == pytest.approx(10, abs=1)              # 20 ms TimedRobot loop
        assert (sim.get(PROBE, "<fast") or 0) == pytest.approx(40, abs=2)   # 5 ms addPeriodic keeps up
        await asyncio.sleep(0.5)
        assert sim.get(PROBE, "<loops") == prev               # no steps, no robot time
    asyncio.run(with_robot(body))


def test_watchdog_releases_clock_and_steps_reengage():
    async def body(sim):
        await sim.engage()
        for n in range(1, 5):
            await sim.step(n)
        loops = sim.get(PROBE, "<loops")
        await sim.until(lambda: sim.get(DEV, "<engaged") is False, 4)          # 2 s watchdog
        await sim.until(lambda: sim.get(PROBE, "<loops") > loops + 5, 3)       # real time: 50 loops/s
        await sim.step(5)                                                      # a step takes the clock back
        assert sim.get(DEV, "<engaged") is True
        frozen = sim.get(PROBE, "<loops")
        await asyncio.sleep(0.5)
        assert sim.get(PROBE, "<loops") == frozen
    asyncio.run(with_robot(body))


def test_grace_period_releases_clock_without_scrimmage():
    async def body(sim):
        # connected, but never engages: like running the robot without scrimmage
        await sim.until(lambda: (sim.get(PROBE, "<loops") or 0) > 5, 5)
    out = asyncio.run(with_robot(body, {"SCRIMMAGE_LOCKSTEP_GRACE_S": "0.5"}))
    assert "running in real time" in out
```

`lockstep/src/scrimmage_lockstep.cpp`:

```cpp
// scrimmage_lockstep: a HALSim extension that lets scrimmage step the robot program's clock.
//
// It pauses WPILib timing as soon as it loads and creates a "ScrimmageLockstep" SimDevice, which
// halsim_ws_client relays to scrimmage over the existing WebSocket. scrimmage writes step_seq;
// a worker thread advances the clock by step_us with HALSIM_StepTiming (which runs due notifiers,
// including TimedRobot's loop, and waits for them) and then reports done_seq. Only the HAL C API
// is used, so one build works with RobotPy's and GradleRIO's HAL of the same WPILib year.
// Design: docs/superpowers/specs/2026-10-11-lockstep-design.md

#include <chrono>
#include <condition_variable>
#include <cstdint>
#include <cstdio>
#include <cstdlib>
#include <mutex>
#include <thread>

#include <hal/Extensions.h>
#include <hal/SimDevice.h>
#include <hal/Value.h>
#include <hal/simulation/MockHooks.h>
#include <hal/simulation/SimDeviceData.h>

namespace {

using Clock = std::chrono::steady_clock;
constexpr auto kWatchdog = std::chrono::seconds(2);
constexpr auto kPoll = std::chrono::milliseconds(50);

struct State {
  HAL_SimValueHandle engage = 0, stepUs = 0, stepSeq = 0, engaged = 0, doneSeq = 0;
  std::mutex m;
  std::condition_variable cv;
  bool engagePending = false;  // guarded by m
  int64_t requestedSeq = 0;    // guarded by m
  bool stop = false;           // guarded by m
  std::thread worker;
};

void Log(const char* msg) { std::fprintf(stderr, "scrimmage_lockstep: %s\n", msg); }

std::chrono::duration<double> GracePeriod() {
  const char* s = std::getenv("SCRIMMAGE_LOCKSTEP_GRACE_S");
  double v = 5.0;
  if (s != nullptr) {
    char* end = nullptr;
    double parsed = std::strtod(s, &end);
    if (end != s && parsed >= 0) v = parsed;
  }
  return std::chrono::duration<double>(v);
}

// Value callbacks run on whichever thread set the value (the WebSocket client's loop for values from
// scrimmage). They only record and wake the worker: stepping timing here would stall that loop.
void OnEngage(const char*, void* param, HAL_SimValueHandle, int32_t, const HAL_Value* value) {
  if (!value->data.v_boolean) return;
  auto* s = static_cast<State*>(param);
  {
    std::lock_guard lock{s->m};
    s->engagePending = true;
  }
  s->cv.notify_one();
}

void OnStepSeq(const char*, void* param, HAL_SimValueHandle, int32_t, const HAL_Value* value) {
  auto* s = static_cast<State*>(param);
  {
    std::lock_guard lock{s->m};
    s->requestedSeq = value->data.v_long;
  }
  s->cv.notify_one();
}

void Worker(State* s) {
  enum class Mode { kPending, kEngaged, kFree };
  Mode mode = Mode::kPending;  // paused at load, waiting for scrimmage
  const auto grace = GracePeriod();
  const auto loaded = Clock::now();
  auto lastActivity = loaded;
  int64_t done = 0;

  // Engage (pausing first if the clock is running free). Called without s->m held, because setting
  // a value fires that value's callbacks on this thread.
  auto engage = [&] {
    if (mode == Mode::kFree) HALSIM_PauseTiming();
    if (mode != Mode::kEngaged) {
      mode = Mode::kEngaged;
      HAL_SetSimValueBoolean(s->engaged, true);
      Log("engaged by scrimmage");
    }
    lastActivity = Clock::now();
  };
  auto release = [&](const char* why) {
    HALSIM_ResumeTiming();
    mode = Mode::kFree;
    HAL_SetSimValueBoolean(s->engaged, false);
    HAL_SetSimValueBoolean(s->engage, false);  // so scrimmage's next engage=true is a change
    Log(why);
  };

  std::unique_lock lock{s->m};
  while (true) {
    s->cv.wait_for(lock, kPoll, [&] { return s->stop || s->engagePending || s->requestedSeq > done; });
    if (s->stop) return;
    const bool wantEngage = s->engagePending;
    s->engagePending = false;
    const int64_t seq = s->requestedSeq;
    lock.unlock();

    if (wantEngage) engage();
    if (seq > done) {
      engage();  // a step request always gets its step, even after the watchdog released the clock
      int64_t us = HAL_GetSimValueLong(s->stepUs);
      if (us > 0) HALSIM_StepTiming(static_cast<uint64_t>(us));
      HAL_SetSimValueLong(s->doneSeq, seq);
      done = seq;
      lastActivity = Clock::now();
    } else {
      auto now = Clock::now();
      if (mode == Mode::kPending && now - loaded > grace) {
        release("scrimmage did not engage within the grace period; running in real time");
      } else if (mode == Mode::kEngaged && now - lastActivity > kWatchdog) {
        release("no step requests from scrimmage for 2 s; running in real time");
      }
    }
    lock.lock();
  }
}

void Shutdown(void* param) {
  auto* s = static_cast<State*>(param);
  {
    std::lock_guard lock{s->m};
    s->stop = true;
  }
  s->cv.notify_one();
  if (s->worker.joinable()) s->worker.join();
}

}  // namespace

extern "C" {

__attribute__((visibility("default"))) int HALSIM_InitExtension(void) {
  HAL_SimDeviceHandle dev = HAL_CreateSimDevice("ScrimmageLockstep");
  if (dev == 0) {
    Log("could not create the ScrimmageLockstep SimDevice; lockstep disabled");
    return 0;
  }
  auto* s = new State;  // lives for the whole process
  s->engage = HAL_CreateSimValueBoolean(dev, "engage", HAL_SimValueInput, false);
  s->stepUs = HAL_CreateSimValueLong(dev, "step_us", HAL_SimValueInput, 5000);
  s->stepSeq = HAL_CreateSimValueLong(dev, "step_seq", HAL_SimValueInput, 0);
  s->engaged = HAL_CreateSimValueBoolean(dev, "engaged", HAL_SimValueOutput, false);
  s->doneSeq = HAL_CreateSimValueLong(dev, "done_seq", HAL_SimValueOutput, 0);

  HALSIM_PauseTiming();  // before the robot's first loop, so every run starts on the same step grid
  HALSIM_RegisterSimValueChangedCallback(s->engage, s, OnEngage, false);
  HALSIM_RegisterSimValueChangedCallback(s->stepSeq, s, OnStepSeq, false);
  s->worker = std::thread(Worker, s);
  HAL_OnShutdown(s, Shutdown);
  Log("loaded; robot clock paused until scrimmage engages");
  return 0;
}

}  // extern "C"
```

```python
"""Loads the scrimmage_lockstep HALSim extension: `python -m robotpy sim --ws-client --scrimmage-lockstep`."""

from __future__ import annotations

import logging
from pathlib import Path

logger = logging.getLogger("scrimmage_lockstep")


def library_path() -> Path:
    return Path(__file__).resolve().parent / "lib" / "libhalsim_scrimmage_lockstep.so"


def loadExtension() -> None:
    import hal

    path = library_path()
    if not path.exists():
        raise ImportError(f"{path} is missing; reinstall scrimmage-lockstep")
    retval = hal.loadOneExtension(str(path))
    if retval != 0:
        logger.warning("loading %s may have failed (error=%d)", path, retval)
```

How to read a failure:
- **`timed out; devices seen: [...]` before any assertion:** the device key differs from `("SimDevice", "ScrimmageLockstep")`. Use the key that's listed in `DEV`/`PROBE` here, and in `LOCKSTEP_DEVICE` in Task 2.
- **The `(n - 1) * 5000 < elapsed <= n * 5000` assertion fails**, meaning outputs arrive after `done_seq`, **or `prev == 10` fails**, meaning notifiers didn't run within `HALSIM_StepTiming`: **STOP.** Commit nothing further and report the failing output to the user. The design's ordering assumption doesn't hold.
- **`fast` far below 40:** `HALSIM_StepTiming` fires each notifier at most once per step. That's acceptable, because the 5 ms default already matches. Relax that one assertion to `>= 35` only if it's off by timing slop, and note it in the commit message.

```python
"""Lockstep stepping: scrimmage drives the robot program's clock through the scrimmage_lockstep extension."""

from __future__ import annotations

import math
import time
from typing import Callable

# The extension's SimDevice as halsim_ws_client relays it (verified by tests/test_lockstep_ext.py).
LOCKSTEP_DEVICE = ("SimDevice", "ScrimmageLockstep")
DEFAULT_STEP = 0.005  # seconds; fine enough for 5 ms addPeriodic loops


def parse_speed(text: str) -> float | None:
    """"max" -> None (as fast as possible), otherwise a positive real-time factor."""
    if text.strip().lower() == "max":
        return None
    try:
        v = float(text)
    except ValueError:
        raise ValueError(f'speed must be a positive number or "max", not {text!r}') from None
    if not (math.isfinite(v) and v > 0):
        raise ValueError(f'speed must be a positive number or "max", not {text!r}')
    return v


def physics_steps_per_step(step: float, timestep: float) -> int:
    """How many physics timesteps make one lockstep step; the step must be a whole multiple."""
    n = round(step / timestep)
    if n < 1 or abs(n * timestep - step) > 1e-9:
        raise ValueError(f"lockstep step {step:g} s must be a whole multiple of the physics timestep {timestep:g} s")
    return n


class Pacer:
    """Keeps simulated time from running ahead of wall time x speed (speed None: never waits)."""

    def __init__(self, speed: float | None, clock: Callable[[], float] = time.monotonic):
        self.speed = speed
        self.clock = clock
        self.wall0 = self.sim0 = 0.0

    def start(self, sim_time: float) -> None:
        self.wall0, self.sim0 = self.clock(), sim_time

    def delay(self, sim_time: float) -> float:
        if self.speed is None:
            return 0.0
        return max(0.0, self.wall0 + (sim_time - self.sim0) / self.speed - self.clock())
```

```python
class FakeRobot:
    """Connects like a robot program's halsim_ws_client and records every frame the bridge sends.

    With lockstep=True it also plays the scrimmage_lockstep extension: it acknowledges engage, and acks each
    step request (or holds the acks when auto_ack=False, until ack_held()).
    """

    def __init__(self, port: int, *, lockstep: bool = False, done_seq: int = 0, auto_ack: bool = True):
        self.port, self.lockstep, self.done_seq, self.auto_ack = port, lockstep, done_seq, auto_ack
        self.frames: list[dict] = []
        self.held: list[int] = []
        self.ws = None
        self._task: asyncio.Task | None = None

    async def __aenter__(self) -> "FakeRobot":
        self.ws = await websockets.connect(f"ws://localhost:{self.port}/wpilibws")
        if self.lockstep:
            await self._send({"<engaged": False, "<done_seq": self.done_seq})
        self._task = asyncio.create_task(self._read())
        return self

    async def __aexit__(self, *exc) -> None:
        await self.close()

    async def close(self) -> None:
        if self._task is not None:
            self._task.cancel()
        await self.ws.close()

    async def _send(self, data: dict) -> None:
        await self.ws.send(frame(*LOCKSTEP_DEVICE, data))

    async def _read(self) -> None:
        try:
            async for raw in self.ws:
                msg = json.loads(raw)
                self.frames.append(msg)
                if not self.lockstep or (msg["type"], msg["device"]) != LOCKSTEP_DEVICE:
                    continue
                data = msg["data"]
                if data.get(">engage") is True:
                    await self._send({"<engaged": True})
                if ">step_seq" in data:
                    if self.auto_ack:
                        self.done_seq = data[">step_seq"]
                        await self._send({"<done_seq": self.done_seq})
                    else:
                        self.held.append(data[">step_seq"])
        except websockets.ConnectionClosed:
            pass

    async def ack_held(self) -> None:
        for seq in self.held:
            self.done_seq = seq
            await self._send({"<done_seq": seq})
        self.held.clear()

    def step_seqs(self) -> list[int]:
        return [m["data"][">step_seq"] for m in self.frames
                if (m["type"], m["device"]) == LOCKSTEP_DEVICE and ">step_seq" in m["data"]]

    def ds_enabled(self) -> list[bool]:
        return [m["data"][">enabled"] for m in self.frames if m["type"] == "DriverStation"]
```

```python
"""HALSim WebSocket server that runs the MuJoCo world alongside a robot program."""

from __future__ import annotations

import asyncio
import csv
import json
import logging
import math
import time
from pathlib import Path
from typing import Any

import websockets

from .protocol import HalState, OutboundCache, frame
from .world import World

log = logging.getLogger("scrimmage")

PHYSICS_TICK = 0.002     # wall-clock seconds between physics catch-up passes (real-time mode)
SENSOR_PERIOD = 0.005    # how often sensor values are pushed to the robot program (real-time mode)
FULL_REFRESH = 0.5       # resend every input, even unchanged ones, this often (covers devices created late)
MAX_LAG = 0.25           # if physics falls this far behind wall time, drop the backlog
DS_PERIOD = 0.02         # simulated seconds between scripted Driver Station frames
LOG_PERIOD = 0.02        # simulated seconds between CSV rows and NT ground-truth updates
VIEWER_PERIOD = 1 / 60   # wall-clock seconds between viewer refreshes


class DSScript:
    """Optional scripted Driver Station for headless runs.

    phases: [{"mode": "disabled"|"auto"|"teleop"|"test", "duration": s,
              "axes": {"0": [..]}, "buttons": {"0": [..]}}]
    """

    def __init__(self, phases: list[dict]):
        self.phases = phases
        self.total = sum(p["duration"] for p in phases)

    def at(self, t: float) -> dict | None:
        for p in self.phases:
            if t < p["duration"]:
                return p
            t -= p["duration"]
        return None

    def frames(self, t: float, match_time_left: float) -> list[str]:
        p = self.at(t)
        if p is None:
            p = {"mode": "disabled"}
        mode = p["mode"]
        out = []
        for idx, axes in p.get("axes", {}).items():
            out.append(frame("Joystick", str(idx), {">axes": axes, ">buttons": p.get("buttons", {}).get(idx, []),
                                                    ">povs": [-1]}))
        out.append(frame("DriverStation", "", {
            ">enabled": mode != "disabled", ">autonomous": mode == "auto", ">test": mode == "test",
            ">ds": True, ">station": "blue1", ">match_time": match_time_left, ">new_data": True}))
        return out


class _Ticks:
    """When each periodic extra last ran, in simulated seconds since the world was reset."""

    def __init__(self) -> None:
        self.refresh = self.ds = self.log = -math.inf


class Bridge:
    def __init__(self, world: World, host: str = "localhost", port: int = 3300, *,
                 ds_script: DSScript | None = None, log_path: Path | None = None,
                 viewer: bool = False, nt: bool = True, exit_after_script: bool = False):
        self.world = world
        self.host, self.port = host, port
        self.ds_script = ds_script
        self.exit_after_script = exit_after_script
        self.log_path = log_path
        self.want_viewer = viewer
        self.want_nt = nt
        self.hal = HalState()
        self.cache = OutboundCache()
        self.ws: Any = None
        self.conn_id = 0                 # bumped on every connection; drivers stop when it changes
        self.exit_code = 0
        self.done = asyncio.Event()
        self._ticks = _Ticks()
        self._nt = self._viewer = self._logf = self._writer = None
        self._last_view = -math.inf

    # ---------------------------------------------------------------- websocket side
    async def _handler(self, ws) -> None:
        path = getattr(getattr(ws, "request", None), "path", "/wpilibws")
        if not path.startswith("/wpilibws") or self.ws is not None:
            await ws.close(1008, "only one robot program at /wpilibws")
            return
        log.info("robot program connected")
        self.ws = ws
        self.conn_id += 1
        self.hal = HalState()
        self._restart_clock()
        try:
            async for raw in ws:
                got = self.hal.apply(raw)
                # Initializing a device in robot code resets its sim values, so resend ours.
                if got is not None and got[1].get("<init") is True:
                    self.cache.forget(*got[0])
        except websockets.ConnectionClosed:
            pass
        finally:
            log.info("robot program disconnected")
            self.ws = None

    async def _send(self, frames: list[str]) -> None:
        if self.ws is None or not frames:
            return
        try:
            for f in frames:
                await self.ws.send(f)
        except websockets.ConnectionClosed:
            pass

    def _connected(self, conn: int) -> bool:
        """Is connection number `conn` still the live one (and are we still running)?"""
        return not self.done.is_set() and self.ws is not None and self.conn_id == conn

    def _restart_clock(self) -> None:
        """Simulated time back to 0: reset the world and resend every input."""
        self.world.reset()
        self.cache.clear()
        self._ticks = _Ticks()

    # ---------------------------------------------------------------- optional extras
    def _setup_nt(self):
        if not self.want_nt:
            return None
        try:
            import ntcore
            from wpimath.geometry import Pose2d
        except ImportError:
            log.info("pyntcore/robotpy-wpimath not installed; skipping NetworkTables ground-truth publishing")
            return None
        inst = ntcore.NetworkTableInstance.create()
        inst.startClient4("mujoco-bridge")
        inst.setServer("localhost")
        pub = inst.getStructTopic("/MuJoCo/GroundTruthPose", Pose2d).publish()
        odo = inst.getDoubleArrayTopic("/SmartDashboard/Field/Robot").subscribe([])
        return inst, pub, odo, Pose2d

    def _setup_viewer(self):
        if not self.want_viewer:
            return None
        import mujoco.viewer
        return mujoco.viewer.launch_passive(self.world.model, self.world.data)

    def _open_log(self) -> None:
        if not self.log_path:
            return
        w = self.world
        self._logf = open(self.log_path, "w", newline="")
        self._writer = csv.writer(self._logf)
        self._writer.writerow(["t", "mode", "x", "y", "heading_deg", "speed", "vbatt", "odo_x", "odo_y", "odo_deg"]
                              + [f"{m.name}_cmd" for m in w.motors] + [f"{m.name}_amps" for m in w.motors])

    def _log_row(self, now: float, mode: str) -> None:
        w = self.world
        x, y, yaw = w.robot_pose()
        odo = [math.nan] * 3
        if self._nt is not None:
            inst, pub, sub, Pose2d = self._nt
            pub.set(Pose2d(x, y, yaw))
            val = sub.get()
            if len(val) >= 3:
                odo = list(val[:3])
        if self._writer:
            self._writer.writerow([f"{now:.3f}", mode, f"{x:.4f}", f"{y:.4f}", f"{math.degrees(yaw):.2f}",
                                   f"{w.robot_speed():.3f}", f"{w.vbatt:.2f}",
                                   *[f"{v:.4f}" for v in odo],
                                   *[f"{m.command:.3f}" for m in w.motors],
                                   *[f"{m.current:.1f}" for m in w.motors]])

    def _sync_viewer(self) -> None:
        """Refresh the viewer at most VIEWER_PERIOD of wall time apart, so fast runs aren't held back by it."""
        if self._viewer is None:
            return
        wall = time.monotonic()
        if wall - self._last_view < VIEWER_PERIOD:
            return
        self._last_view = wall
        if not self._viewer.is_running():
            self.done.set()
            return
        self._viewer.sync()

    # ---------------------------------------------------------------- per-tick work, shared by both drivers
    async def _push_sensors(self) -> None:
        await self._send(self.cache.frames(self.world.sensor_updates(self.hal)))

    async def _on_tick(self, now: float) -> None:
        """Periodic extras, on simulated time since the robot program connected."""
        t = self._ticks
        if now - t.refresh >= FULL_REFRESH:
            t.refresh = now
            self.cache.clear()
        mode = "external"
        if self.ds_script is not None:
            phase = self.ds_script.at(now)
            mode = phase["mode"] if phase else "done"
            if now - t.ds >= DS_PERIOD:
                t.ds = now
                await self._send(self.ds_script.frames(now, max(0.0, self.ds_script.total - now)))
            if phase is None and self.exit_after_script:
                self.done.set()
        if now - t.log >= LOG_PERIOD:
            t.log = now
            self._log_row(now, mode)
        self._sync_viewer()

    # ---------------------------------------------------------------- drivers
    async def _run_realtime(self, conn: int) -> str:
        """Step physics to keep pace with the wall clock until the connection ends."""
        w = self.world
        wall0, sim0 = time.monotonic(), w.time
        last_sensor = -math.inf
        while self._connected(conn):
            target = time.monotonic() - wall0
            if target - (w.time - sim0) > MAX_LAG:
                log.warning("physics fell %.0f ms behind real time; skipping ahead",
                            1000 * (target - (w.time - sim0)))
                sim0 = w.time - target
            while (w.time - sim0) < target:
                w.step(self.hal)
            now = w.time
            await self._on_tick(now)
            if now - last_sensor >= SENSOR_PERIOD:
                last_sensor = now
                await self._push_sensors()
            await asyncio.sleep(PHYSICS_TICK)
        return "disconnected"

    async def _physics(self) -> None:
        self._nt = self._setup_nt()
        self._viewer = self._setup_viewer()
        self._open_log()
        try:
            while not self.done.is_set():
                if self.ws is None:
                    await asyncio.sleep(0.05)   # idle until a robot program connects
                    self._sync_viewer()
                    continue
                await self._run_realtime(self.conn_id)
        finally:
            if self._logf:
                self._logf.close()
            if self._viewer is not None:
                self._viewer.close()

    async def run(self) -> None:
        async with websockets.serve(self._handler, self.host, self.port, max_size=None):
            log.info("HALSim WebSocket server listening on ws://%s:%d/wpilibws", self.host, self.port)
            physics = asyncio.create_task(self._physics())
            await self.done.wait()
            physics.cancel()
            try:
                await physics
            except asyncio.CancelledError:
                pass
            if self.ws is not None:
                await self.ws.close()


def load_ds_script(arg: str) -> DSScript:

        mode, dur = part.split(":")
        phases.append({"mode": mode.strip(), "duration": float(dur)})
    return DSScript(phases)
```

```python
class LockstepDriver:
    """Alternates physics steps with robot program steps until the connection ends.

    Each cycle: step physics by one lockstep step, run the per-tick extras, push sensors, then ask the
    extension to step the robot clock (>step_seq = n) and wait for <done_seq >= n. Everything travels on
    the one WebSocket in order, so once done_seq arrives, that step's motor outputs are already in hal.
    """

    def __init__(self, bridge: Bridge, conn: int):
        self.b = bridge
        self.conn = conn

    def _get(self, key: str, default=None):
        return self.b.hal.get(*LOCKSTEP_DEVICE, key, default)

    async def _wait_for(self, pred: Callable[[], bool], what: str) -> bool:
        """Wait until pred() holds; False if the connection ended first. Warns while the robot is stalled."""
        b = self.b
        next_warn = time.monotonic() + STALL_FIRST_WARNING
        while not pred():
            if not b._connected(self.conn):
                return False
            b.lockstep_changed.clear()
            try:
                await asyncio.wait_for(b.lockstep_changed.wait(), max(0.0, next_warn - time.monotonic()))
            except TimeoutError:
                log.warning("waiting on robot program (%s)", what)
                next_warn = time.monotonic() + STALL_REPEAT
        return True

    async def run(self) -> None:
        b, w = self.b, self.b.world
        step_us = round(b.step * 1e6)
        # step_us goes with engage (not with each step_seq) so the extension never reads a stale value
        await b._send([frame(*LOCKSTEP_DEVICE, {">step_us": step_us, ">engage": True})])
        if not await self._wait_for(lambda: self._get("<engaged") is True, "engage"):
            return
        log.info("lockstep engaged: %g ms steps, speed %s",
                 b.step * 1000, "max" if b.speed is None else f"{b.speed:g}x")
        b._restart_clock()
        seq = int(self._get("<done_seq", 0) or 0)  # the extension keeps counting across reconnects
        pacer = Pacer(b.speed)
        pacer.start(w.time)
        while b._connected(self.conn):
            for _ in range(b.physics_per_step):
                w.step(b.hal)
            now = w.time
            await b._on_tick(now)
            if b.done.is_set():
                return
            await b._push_sensors()
            seq += 1
            n = seq
            await b._send([frame(*LOCKSTEP_DEVICE, {">step_seq": n})])
            if not await self._wait_for(lambda: int(self._get("<done_seq", 0) or 0) >= n, f"step {n}"):
                return
            delay = pacer.delay(now)
            if delay > 0:
                await asyncio.sleep(delay)
```

````markdown
## Lockstep (Linux, untested from Gradle)

The lockstep extension is a HALSim extension like the WebSocket client, so it loads from the
`HALSIM_EXTENSIONS` environment variable (a `:`-separated list of library paths). Build and locate it with:

```bash
pip install ./lockstep            # from the Scrimmage checkout; needs RobotPy's HAL wheel to build
python -m scrimmage_lockstep         # prints the path to libhalsim_scrimmage_lockstep.so
```

GradleRIO also sets `HALSIM_EXTENSIONS` for the extensions you tick, so the path has to be appended to
its list rather than replacing it. The exact `build.gradle` lines haven't been worked out yet, because
no GradleRIO toolchain was available where this was built. The library uses only the HAL's C API, so the
same `.so` should load into a 2026 Java robot program. When it works, scrimmage logs `lockstep engaged`.
````
