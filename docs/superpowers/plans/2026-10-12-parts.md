# Parts and Assembler (sub-project 4a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Robots are described as `[[part]]` entries (stock parts or `part.toml` folders) that Scrimmage
assembles into a MuJoCo model and device bindings, replacing hand-written MJCF.

**Architecture:** `scrimmage/parts/` holds a plain-data part model (`model.py`, loads and dumps
`part.toml`), a stock library of Python builders (`stock/`), a field generator (`field.py`), a slot-to-binding
translator (`ids.py`) and the assembler (`assemble.py`), which builds an `mujoco.MjSpec`: one sub-spec per
part, attached under `<instance>.` prefixes. `World` calls the assembler when the config has `[[part]]` and then
runs unchanged on the generated model and bindings.

**Tech Stack:** Python 3.12, MuJoCo 3.15 (`MjSpec`), tomllib + tomli-w, pytest. Java/Gradle only in Task 7.

**Spec:** docs/superpowers/specs/2026-10-12-parts-design.md

## Global Constraints

- Units in files: meters, kilograms, degrees, seconds; radians internally. Robot frame: x forward, y left, z up.
- `part.toml` header `[part] name = "...", format = 1`; a larger `format` is an error telling the user to upgrade.
- Generated names are `<instance>.<name>`; instance names match `[A-Za-z0-9_]+`.
- A config has `[model] mjcf` or `[[part]]`, never both; hand-written `[[motor]]`/`[[encoder]]`/`[[gyro]]` only with `[model]`.
- Contact bits: robot geoms that collide `contype = 2, conaffinity = 1`; non-colliding robot geoms `0, 0`; field geoms `contype = 1, conaffinity = 2`.
- Every user mistake raises `PartError` (a `ValueError`) whose message names the file and/or `parts[i] '<name>'` and the key; it surfaces as `ConfigError` and exit code 2 through the existing `build_world`.
- Short ID forms: `TalonFX:N`, `CANcoder:N`, `Pigeon2:N` → `ctre`; `PWM:N` → `pwm = N`; `DIO:N` → `channel_a = N`. Table form uses today's binding keys; the part supplies `joint`, `body`, `motor`, `count`, `gear_ratio`, `ratio`, `name`, `efficiency` (setting them in `ids` is an error). `invert` in `ids` flips the slot's `invert`.
- Field names unchanged from `models/kitbot.xml`: `carpet`, `wall_blue`, `wall_red`, `wall_left`, `wall_right`, `obstacle`.
- Linux only; Python is `.venv/bin/python`; the WPILib JDK is `~/wpilib/2026/jdk`.
- Never commit CTRE-authored files (the Tuner X project is downloaded at test time).

## Review Focus

2. A typo in a stock parameter or slot name (`gear = 9`, `ids = { lifts = ... }`) must list the valid names, not be ignored. (Tasks 2 and 4 tests.)
3. A part attached to a mount on a moving body (arm on an elevator carriage) must move with that body. (Task 3 test.)
4. A slot with `count = 2` given a list of 3 IDs, or an ID of the wrong kind (`gyro = "TalonFX:3"`), must fail with the expected form. (Task 4 tests.)

```python
"""A part: a mechanism's bodies, joints, couplings, device slots and mount points, and its part.toml form.

Files use meters, kilograms and degrees; the dataclasses keep file units (degrees for hinge ranges and `rot`)
and the assembler converts. See docs/parts.md for the format."""

from __future__ import annotations

import math
import tomllib
from dataclasses import dataclass, field
from pathlib import Path

import tomli_w

from ..motors import MOTORS

FORMAT = 1
AXES = {"x": (1.0, 0.0, 0.0), "y": (0.0, 1.0, 0.0), "z": (0.0, 0.0, 1.0)}
SHAPES = ("box", "cylinder", "sphere", "mesh")


class PartError(ValueError):
    """A mistake in a part or a [[part]] entry. The message names where and which key."""


@dataclass
class Geom:
    shape: str                                   # one of SHAPES
    size: tuple[float, ...] | str                # box: full x, y, z; cylinder: radius, length; sphere: (r,); mesh: path
    axis: str = "z"                              # cylinders only
    pos: tuple[float, float, float] = (0.0, 0.0, 0.0)
    rot: tuple[float, float, float] = (0.0, 0.0, 0.0)
    collide: bool = True
    friction: float | None = None
    color: tuple[float, float, float, float] | None = None
    condim: int | None = None
    solref: tuple[float, float] | None = None


@dataclass
class Joint:
    name: str
    kind: str                                    # "hinge" | "slide"
    axis: tuple[float, float, float]
    range: tuple[float, float] | None = None     # degrees (hinge) or meters (slide)
    damping: float = 0.0
    frictionloss: float = 0.0
    armature: float = 0.0
    spring: tuple[float, float] | None = None    # (stiffness, rest) rest in degrees or meters


@dataclass
class Body:
    name: str
    parent: str | None
    mass: float
    geoms: list[Geom]
    pos: tuple[float, float, float] = (0.0, 0.0, 0.0)
    rot: tuple[float, float, float] = (0.0, 0.0, 0.0)
    joint: Joint | None = None
    com: tuple[float, float, float] | None = None
    inertia: tuple[float, float, float] | None = None   # diagonal, about com; needs com


@dataclass
class Coupling:
    joints: tuple[str, str]                      # (a, b): b = ratio * a
    ratio: float


@dataclass
class MotorSlot:
    slot: str
    joint: str
    motor: str
    count: int = 1
    gearing: float = 1.0                         # motor radians per joint unit (rad or m)
    invert: bool = False
    efficiency: float = 1.0


@dataclass
class EncoderSlot:
    slot: str
    joint: str
    ratio: float = 1.0                           # sensor turns per joint unit (turn or m)
    invert: bool = False


@dataclass
class GyroSlot:
    slot: str
    body: str


@dataclass
class Mount:
    name: str
    body: str
    pos: tuple[float, float, float] = (0.0, 0.0, 0.0)
    rot: tuple[float, float, float] = (0.0, 0.0, 0.0)


@dataclass
class Part:
    name: str
    bodies: list[Body]
    couplings: list[Coupling] = field(default_factory=list)
    motors: list[MotorSlot] = field(default_factory=list)
    encoders: list[EncoderSlot] = field(default_factory=list)
    gyros: list[GyroSlot] = field(default_factory=list)
    mounts: list[Mount] = field(default_factory=list)
    base_dir: Path | None = None                 # where mesh paths resolve

    def slot_kinds(self) -> dict[str, str]:
        out = {s.slot: "motor" for s in self.motors}
        out.update({s.slot: "encoder" for s in self.encoders})
        out.update({s.slot: "gyro" for s in self.gyros})
        return out

    def joint_names(self) -> list[str]:
        return [b.joint.name for b in self.bodies if b.joint is not None]


# ---------------------------------------------------------------------------------------------- helpers

def quat_from_rpy(rot_deg) -> list[float]:
    """Roll, pitch, yaw in degrees about the fixed x, y, z axes (applied in that order) as a wxyz quaternion."""
    def axis_quat(i: int, a: float) -> list[float]:
        q = [math.cos(a / 2), 0.0, 0.0, 0.0]
        q[1 + i] = math.sin(a / 2)
        return q

    def mul(p, q):
        pw, px, py, pz = p
        qw, qx, qy, qz = q
        return [pw * qw - px * qx - py * qy - pz * qz, pw * qx + px * qw + py * qz - pz * qy,
                pw * qy - px * qz + py * qw + pz * qx, pw * qz + px * qy - py * qx + pz * qw]

    r, p, y = (math.radians(float(v)) for v in rot_deg)
    return mul(axis_quat(2, y), mul(axis_quat(1, p), axis_quat(0, r)))


class _Ctx:
    """Builds error messages: '<source>: <where>: <message>'."""

    def __init__(self, source: str):
        self.source = source

    def err(self, where: str, msg: str) -> PartError:
        return PartError(f"{self.source}: {where}: {msg}" if where else f"{self.source}: {msg}")

    def keys(self, d: dict, allowed: tuple[str, ...], where: str) -> None:
        if not isinstance(d, dict):
            raise self.err(where, f"must be a table, not {d!r}")
        for k in d:
            if k not in allowed:
                raise self.err(where, f"unknown key {k!r}; allowed: {', '.join(allowed)}")

    def num(self, d: dict, key: str, where: str, default=None, *, positive=False, nonneg=False) -> float:
        if key not in d:
            if default is None:
                raise self.err(where, f"missing {key}")
            return default
        v = d[key]
        if isinstance(v, bool) or not isinstance(v, (int, float)):
            raise self.err(where, f"{key} must be a number, not {v!r}")
        if positive and not v > 0:
            raise self.err(where, f"{key} must be greater than 0, got {v}")
        if nonneg and v < 0:
            raise self.err(where, f"{key} must be 0 or more, got {v}")
        return float(v)

    def vec(self, d: dict, key: str, where: str, n: int = 3, default=None) -> tuple[float, ...]:
        if key not in d:
            if default is None:
                raise self.err(where, f"missing {key}")
            return default
        v = d[key]
        if not (isinstance(v, list) and len(v) == n and all(isinstance(x, (int, float)) and not isinstance(x, bool) for x in v)):
            raise self.err(where, f"{key} must be a list of {n} numbers, not {v!r}")
        return tuple(float(x) for x in v)

    def name(self, d: dict, key: str, where: str) -> str:
        v = d.get(key)
        if not isinstance(v, str) or not v:
            raise self.err(where, f"{key} must be a non-empty string, not {v!r}")
        return v

    def axis(self, v, where: str, key: str) -> tuple[float, float, float]:
        if isinstance(v, str) and v in AXES:
            return AXES[v]
        if isinstance(v, list) and len(v) == 3 and all(isinstance(x, (int, float)) for x in v):
            n = math.sqrt(sum(float(x) ** 2 for x in v))
            if n > 0:
                return tuple(float(x) / n for x in v)
        raise self.err(where, f"{key} must be \"x\", \"y\", \"z\" or a non-zero [x, y, z], not {v!r}")


GEOM_KEYS = SHAPES + ("axis", "pos", "rot", "collide", "friction", "color", "condim", "solref")
JOINT_KEYS = ("name", "hinge", "slide", "range", "damping", "frictionloss", "armature", "spring")
BODY_KEYS = ("name", "parent", "mass", "pos", "rot", "geom", "joint", "com", "inertia")


def _geom(c: _Ctx, g: dict, where: str, base_dir: Path | None) -> Geom:
    c.keys(g, GEOM_KEYS, where)
    shapes = [s for s in SHAPES if s in g]
    if len(shapes) != 1:
        raise c.err(where, "a geom needs exactly one of box, cylinder, sphere, mesh")
    shape = shapes[0]
    if shape == "box":
        size = c.vec(g, "box", where)
        if min(size) <= 0:
            raise c.err(where, "box sizes must be greater than 0")
    elif shape == "cylinder":
        size = c.vec(g, "cylinder", where, 2)
        if min(size) <= 0:
            raise c.err(where, "cylinder [radius, length] must be greater than 0")
    elif shape == "sphere":
        size = (c.num(g, "sphere", where, positive=True),)
    else:
        size = g["mesh"]
        if not isinstance(size, str):
            raise c.err(where, f"mesh must be a file path, not {size!r}")
        if base_dir is not None and not (base_dir / size).is_file():
            raise c.err(where, f"mesh file not found: {(base_dir / size)}")
    axis = g.get("axis", "z")
    if axis not in AXES:
        raise c.err(where, f"axis must be \"x\", \"y\" or \"z\", not {axis!r}")
    color = c.vec(g, "color", where, 4) if "color" in g else None
    solref = c.vec(g, "solref", where, 2) if "solref" in g else None
    collide = g.get("collide", True)
    if not isinstance(collide, bool):
        raise c.err(where, f"collide must be true or false, not {collide!r}")
    condim = g.get("condim")
    if condim is not None and condim not in (1, 3, 4, 6):
        raise c.err(where, f"condim must be 1, 3, 4 or 6, not {condim!r}")
    return Geom(shape, size, axis, c.vec(g, "pos", where, default=(0.0, 0.0, 0.0)),
                c.vec(g, "rot", where, default=(0.0, 0.0, 0.0)), collide,
                c.num(g, "friction", where, positive=True) if "friction" in g else None, color, condim, solref)


def _joint(c: _Ctx, j: dict, where: str) -> Joint:
    c.keys(j, JOINT_KEYS, where)
    name = c.name(j, "name", where)
    kinds = [k for k in ("hinge", "slide") if k in j]
    if len(kinds) != 1:
        raise c.err(where, "a joint needs exactly one of hinge = <axis> or slide = <axis>")
    kind = kinds[0]
    rng = None
    if "range" in j:
        rng = c.vec(j, "range", where, 2)
        if rng[0] >= rng[1]:
            raise c.err(where, f"range must be [min, max] with min < max, got {list(rng)}")
    spring = None
    if "spring" in j:
        s = j["spring"]
        c.keys(s, ("stiffness", "rest"), where + " spring")
        spring = (c.num(s, "stiffness", where + " spring", nonneg=True), c.num(s, "rest", where + " spring", 0.0))
    return Joint(name, kind, c.axis(j[kind], where, kind), rng, c.num(j, "damping", where, 0.0, nonneg=True),
                 c.num(j, "frictionloss", where, 0.0, nonneg=True), c.num(j, "armature", where, 0.0, nonneg=True),
                 spring)


def _table_list(c: _Ctx, d: dict, key: str) -> list[dict]:
    v = d.get(key, [])
    if not isinstance(v, list) or not all(isinstance(x, dict) for x in v):
        raise c.err("", f"[[{key}]] must be an array of tables")
    return v


def part_from_dict(d: dict, source: str, base_dir: Path | None) -> Part:
    """Validate a parsed part.toml (or a stock builder's dict) into a Part."""
    c = _Ctx(source)
    c.keys(d, ("part", "body", "coupling", "motor", "encoder", "gyro", "mount"), "")
    head = d.get("part")
    if not isinstance(head, dict):
        raise c.err("", "missing the [part] table (name = \"...\", format = 1)")
    c.keys(head, ("name", "format"), "[part]")
    fmt = head.get("format", FORMAT)
    if not isinstance(fmt, int) or isinstance(fmt, bool):
        raise c.err("[part]", f"format must be an integer, not {fmt!r}")
    if fmt > FORMAT:
        raise c.err("[part]", f"format {fmt} was made by a newer scrimmage (this one reads {FORMAT}); upgrade scrimmage")
    name = c.name(head, "name", "[part]")

    bodies: list[Body] = []
    seen_joints: set[str] = set()
    for i, b in enumerate(_table_list(c, d, "body")):
        where = f"body {b.get('name', i)!r}"
        c.keys(b, BODY_KEYS, where)
        bname = c.name(b, "name", where)
        where = f"body {bname!r}"
        if any(x.name == bname for x in bodies):
            raise c.err(where, "defined twice")
        parent = b.get("parent")
        if not bodies:
            if parent is not None:
                raise c.err(where, "the first body is the part's root and has no parent")
        elif not isinstance(parent, str) or not any(x.name == parent for x in bodies):
            raise c.err(where, f"parent {parent!r} isn't an earlier body ({', '.join(x.name for x in bodies)})")
        geoms = [_geom(c, g, f"{where} geom {k}", base_dir) for k, g in enumerate(b.get("geom", []))]
        joint = None
        if "joint" in b:
            if not bodies:
                raise c.err(where, f"the root body {bname!r} can't have a joint: it moves with what it's attached to")
            joint = _joint(c, b["joint"], f"{where} joint")
            if joint.name in seen_joints:
                raise c.err(where, f"joint {joint.name!r} is defined twice")
            seen_joints.add(joint.name)
        com = c.vec(b, "com", where) if "com" in b else None
        inertia = c.vec(b, "inertia", where) if "inertia" in b else None
        if inertia is not None and (com is None or min(inertia) <= 0):
            raise c.err(where, "inertia needs com, and its three values must be greater than 0")
        bodies.append(Body(bname, parent, c.num(b, "mass", where, positive=True), geoms,
                           c.vec(b, "pos", where, default=(0.0, 0.0, 0.0)), c.vec(b, "rot", where, default=(0.0, 0.0, 0.0)),
                           joint, com, inertia))
    if not bodies:
        raise c.err("", "a part needs at least one [[body]]")
    joints = sorted(seen_joints)
    body_names = [b.name for b in bodies]

    def need_joint(j, where):
        if j not in seen_joints:
            raise c.err(where, f"no joint {j!r}; the part's joints: {', '.join(joints) or 'none'}")
        return j

    couplings = []
    for k, cp in enumerate(_table_list(c, d, "coupling")):
        where = "coupling"
        c.keys(cp, ("joints", "ratio"), where)
        js = cp.get("joints")
        if not (isinstance(js, list) and len(js) == 2 and all(isinstance(x, str) for x in js)):
            raise c.err(where, "joints must be [\"a\", \"b\"] (b = ratio * a)")
        ratio = c.num(cp, "ratio", where)
        if ratio == 0:
            raise c.err(where, "ratio must not be 0")
        couplings.append(Coupling((need_joint(js[0], where), need_joint(js[1], where)), ratio))

    slots: set[str] = set()

    def slot_name(s: dict, kind: str) -> tuple[str, str]:
        n = c.name(s, "slot", f"{kind} slot")
        if n in slots:
            raise c.err(f"{kind} slot {n!r}", f"slot {n!r} is defined twice")
        slots.add(n)
        return n, f"{kind} slot {n!r}"

    motors = []
    for s in _table_list(c, d, "motor"):
        c.keys(s, ("slot", "joint", "motor", "count", "gearing", "invert", "efficiency"), "motor slot")
        n, where = slot_name(s, "motor")
        motor = c.name(s, "motor", where)
        if motor not in MOTORS:
            raise c.err(where, f"Unknown motor {motor!r}. Known motors: {', '.join(sorted(MOTORS))}")
        count = s.get("count", 1)
        if not isinstance(count, int) or isinstance(count, bool) or count < 1:
            raise c.err(where, f"count must be a whole number of motors (1 or more), not {count!r}")
        motors.append(MotorSlot(n, need_joint(c.name(s, "joint", where), where), motor, count,
                                c.num(s, "gearing", where, 1.0, positive=True), bool(s.get("invert", False)),
                                c.num(s, "efficiency", where, 1.0, positive=True)))
    encoders = []
    for s in _table_list(c, d, "encoder"):
        c.keys(s, ("slot", "joint", "ratio", "invert"), "encoder slot")
        n, where = slot_name(s, "encoder")
        encoders.append(EncoderSlot(n, need_joint(c.name(s, "joint", where), where),
                                    c.num(s, "ratio", where, 1.0), bool(s.get("invert", False))))
    gyros = []
    for s in _table_list(c, d, "gyro"):
        c.keys(s, ("slot", "body"), "gyro slot")
        n, where = slot_name(s, "gyro")
        body = c.name(s, "body", where)
        if body not in body_names:
            raise c.err(where, f"no body {body!r}; the part's bodies: {', '.join(body_names)}")
        gyros.append(GyroSlot(n, body))
    mounts = []
    for m in _table_list(c, d, "mount"):
        c.keys(m, ("name", "body", "pos", "rot"), "mount")
        n = c.name(m, "name", "mount")
        where = f"mount {n!r}"
        if any(x.name == n for x in mounts):
            raise c.err(where, "defined twice")
        body = c.name(m, "body", where)
        if body not in body_names:
            raise c.err(where, f"no body {body!r}; the part's bodies: {', '.join(body_names)}")
        mounts.append(Mount(n, body, c.vec(m, "pos", where, default=(0.0, 0.0, 0.0)),
                            c.vec(m, "rot", where, default=(0.0, 0.0, 0.0))))
    return Part(name, bodies, couplings, motors, encoders, gyros, mounts, base_dir)


def _axis_out(v: tuple[float, float, float]):
    for k, a in AXES.items():
        if tuple(v) == a:
            return k
    return list(v)


def part_to_dict(p: Part) -> dict:
    """The part as part.toml data (defaults left out)."""
    def geom(g: Geom) -> dict:
        out: dict = {g.shape: (list(g.size) if g.shape in ("box", "cylinder") else
                               g.size[0] if g.shape == "sphere" else g.size)}
        if g.shape == "cylinder" and g.axis != "z":
            out["axis"] = g.axis
        for key, val, dflt in (("pos", g.pos, (0.0, 0.0, 0.0)), ("rot", g.rot, (0.0, 0.0, 0.0))):
            if tuple(val) != dflt:
                out[key] = list(val)
        if not g.collide:
            out["collide"] = False
        for key in ("friction", "condim"):
            if getattr(g, key) is not None:
                out[key] = getattr(g, key)
        for key in ("color", "solref"):
            if getattr(g, key) is not None:
                out[key] = list(getattr(g, key))
        return out

    def joint(j: Joint) -> dict:
        out: dict = {"name": j.name, j.kind: _axis_out(j.axis)}
        if j.range is not None:
            out["range"] = list(j.range)
        for key in ("damping", "frictionloss", "armature"):
            if getattr(j, key):
                out[key] = getattr(j, key)
        if j.spring is not None:
            out["spring"] = {"stiffness": j.spring[0], "rest": j.spring[1]}
        return out

    bodies = []
    for b in p.bodies:
        out: dict = {"name": b.name}
        if b.parent is not None:
            out["parent"] = b.parent
        out["mass"] = b.mass
        for key, val in (("pos", b.pos), ("rot", b.rot)):
            if tuple(val) != (0.0, 0.0, 0.0):
                out[key] = list(val)
        if b.com is not None:
            out["com"] = list(b.com)
        if b.inertia is not None:
            out["inertia"] = list(b.inertia)
        out["geom"] = [geom(g) for g in b.geoms]
        if b.joint is not None:
            out["joint"] = joint(b.joint)
        bodies.append(out)
    d: dict = {"part": {"name": p.name, "format": FORMAT}, "body": bodies}
    if p.couplings:
        d["coupling"] = [{"joints": list(cp.joints), "ratio": cp.ratio} for cp in p.couplings]
    if p.motors:
        d["motor"] = [{k: v for k, v in (("slot", s.slot), ("joint", s.joint), ("motor", s.motor), ("count", s.count),
                                         ("gearing", s.gearing), ("invert", s.invert), ("efficiency", s.efficiency))
                       if not ((k == "count" and v == 1) or (k == "invert" and not v) or (k == "efficiency" and v == 1.0))}
                      for s in p.motors]
    if p.encoders:
        d["encoder"] = [{k: v for k, v in (("slot", s.slot), ("joint", s.joint), ("ratio", s.ratio), ("invert", s.invert))
                         if not ((k == "ratio" and v == 1.0) or (k == "invert" and not v))} for s in p.encoders]
    if p.gyros:
        d["gyro"] = [{"slot": s.slot, "body": s.body} for s in p.gyros]
    if p.mounts:
        d["mount"] = [{k: v for k, v in (("name", m.name), ("body", m.body), ("pos", list(m.pos)), ("rot", list(m.rot)))
                       if not (k in ("pos", "rot") and v == [0.0, 0.0, 0.0])} for m in p.mounts]
    return d


def load_part(path: Path) -> Part:
    """Load a part folder (holding part.toml) or a part.toml file."""
    path = Path(path)
    file = path / "part.toml" if path.is_dir() else path
    try:
        raw = tomllib.loads(file.read_text())
    except FileNotFoundError:
        raise PartError(f"part file not found: {file}") from None
    except (OSError, UnicodeDecodeError) as e:
        raise PartError(f"can't read part file {file}: {e}") from None
    except tomllib.TOMLDecodeError as e:
        raise PartError(f"{file}: {e}") from None
    return part_from_dict(raw, str(file), file.parent)


def dump_part(p: Part, path: Path) -> None:
    Path(path).write_text(tomli_w.dumps(part_to_dict(p)))
```

```python
"""The stock part library: Python builders with typed, documented parameters.

A builder takes validated parameters and returns part.toml-shaped data; build_stock() validates both."""

from __future__ import annotations

from dataclasses import dataclass, field
from typing import Any, Callable

from ..model import Part, PartError, part_from_dict


@dataclass(frozen=True)
class Param:
    name: str
    unit: str
    default: Any
    doc: str
    kind: str = "float"            # float | int | str | bool | ratio (named choice or number) | pair
    min: float | None = None       # inclusive
    max: float | None = None       # inclusive; a callable(params) -> float is allowed for dependent limits
    choices: tuple | None = None
    positive: bool = False


@dataclass(frozen=True)
class Stock:
    name: str
    doc: str
    params: tuple[Param, ...]
    build: Callable[[dict], dict]
    slots: tuple[str, ...]
    mounts: tuple[str, ...]
    note: str = ""


REGISTRY: dict[str, Stock] = {}


def register(stock: Stock) -> Stock:
    REGISTRY[stock.name] = stock
    return stock


def _check(p: Param, v: Any, where: str, params: dict) -> Any:
    def bad(msg):
        return PartError(f"{where}: {p.name} {msg}")

    if p.kind in ("float", "int"):
        if isinstance(v, bool) or not isinstance(v, (int, float)) or (p.kind == "int" and not isinstance(v, int)):
            raise bad(f"must be {'a whole number' if p.kind == 'int' else 'a number'} ({p.unit}), not {v!r}")
        if p.positive and not v > 0:
            raise bad(f"must be greater than 0, got {v}")
        if p.min is not None and v < p.min:
            raise bad(f"must be at least {p.min}, got {v}")
        hi = p.max(params) if callable(p.max) else p.max
        if hi is not None and v > hi:
            raise bad(f"must be at most {round(hi, 6)}, got {v}")
        return float(v) if p.kind == "float" else v
    if p.kind == "bool":
        if not isinstance(v, bool):
            raise bad(f"must be true or false, not {v!r}")
        return v
    if p.kind == "str":
        if v not in p.choices:
            raise bad(f"must be one of {', '.join(map(str, p.choices))}, not {v!r}")
        return v
    if p.kind == "ratio":
        if isinstance(v, str) and v in p.choices:
            return v
        if not isinstance(v, bool) and isinstance(v, (int, float)) and v > 0:
            return float(v)
        raise bad(f"must be one of {', '.join(p.choices)} or a number greater than 0, not {v!r}")
    if p.kind == "pair":
        if not (isinstance(v, list) and len(v) == 2 and all(isinstance(x, (int, float)) and not isinstance(x, bool)
                                                            for x in v) and v[0] < v[1]):
            raise bad(f"must be [min, max] with min < max ({p.unit}), not {v!r}")
        return (float(v[0]), float(v[1]))
    raise AssertionError(p.kind)


FAMILIES = ("chassis", "mechanisms", "swerve", "differential")


def _load_all() -> None:
    """Import every stock family module (importing registers its parts). Families added by later tasks may
    not exist yet."""
    import importlib
    for mod in FAMILIES:
        try:
            importlib.import_module(f"{__name__}.{mod}")
        except ModuleNotFoundError as e:
            if e.name != f"{__name__}.{mod}":
                raise


def build_stock(name: str, given: dict, where: str) -> Part:
    _load_all()
    stock = REGISTRY.get(name)
    if stock is None:
        raise PartError(f"{where}: unknown stock part {name!r}; stock parts: {', '.join(sorted(REGISTRY))}")
    names = [p.name for p in stock.params]
    for k in given:
        if k not in names:
            raise PartError(f"{where}: unknown parameter {k!r} for {name}; parameters: {', '.join(names)}")
    params: dict = {p.name: p.default for p in stock.params}
    params.update(given)
    for p in stock.params:   # check after defaults are in, so dependent limits see the final values
        params[p.name] = _check(p, params[p.name], where, params)
    return part_from_dict(stock.build(params), f"{where} (stock {name})", None)


def describe(name: str | None) -> str:
    _load_all()
    if name is None:
        return "\n".join(f"{s.name:20} {s.doc}" for s in sorted(REGISTRY.values(), key=lambda s: s.name))
    s = REGISTRY.get(name)
    if s is None:
        raise PartError(f"unknown stock part {name!r}; stock parts: {', '.join(sorted(REGISTRY))}")
    lines = [f"{s.name}: {s.doc}", ""]
    if s.note:
        lines += [s.note, ""]
    lines.append("parameters:")
    for p in s.params:
        rng = ""
        if p.choices:
            rng = f" (one of {', '.join(map(str, p.choices))}{' or a number' if p.kind == 'ratio' else ''})"
        lines.append(f"  {p.name} = {p.default!r} {p.unit}{rng}: {p.doc}")
    lines += ["", f"slots: {', '.join(s.slots) or 'none'}", f"mounts: {', '.join(s.mounts) or 'none'}"]
    return "\n".join(lines)
```

### Task 3: The assembler and the field

**Files:**
- Create: `scrimmage/parts/field.py`, `scrimmage/parts/assemble.py`, `tests/test_assemble.py`

**Interfaces:**
- Consumes: Task 1 model, Task 2 `build_stock`.
- Produces:
  - `add_field(spec: mujoco.MjSpec, cfg: dict) -> None` (cfg is the `[field]` table).
  - `@dataclass Instance(name, part: Part, source: str, attach: str | None, pos, rot, ids: dict, where: str)`.
  - `@dataclass Built(model: mujoco.MjModel, spec: mujoco.MjSpec, robot_body: str, instances: list[Instance], bindings: dict[str, list[dict]], warnings: list[str])`.
  - `assemble(cfg: dict, cfg_dir: Path) -> Built`. In this task `bindings` stays `{"motor": [], "encoder": [], "gyro": []}` and `warnings` `[]`; Task 4 fills them.
  - `part_spec(part: Part) -> mujoco.MjSpec` (standalone part, unprefixed names, masses set).

Rules to implement (spec "The robot config"):
- `cfg["part"]` must be a list of tables; each needs `name` matching `[A-Za-z0-9_]+`, unique, and exactly one of `stock` / `path` (`path` relative to `cfg_dir`). Other keys except `attach`, `pos`, `rot`, `ids` are stock parameters (a `path` part with extra keys is an error naming them).
- Exactly one part without `attach` (the root). `attach = "<instance>.<mount or body>"`, mount names first. Unknown instance → list instances; unknown mount/body → list both. Cycles → name the parts.
- Build order: root first, then parts whose target is already placed.
- Root: a world-body frame at `(start_pose x, y, 0)` with yaw `start_pose heading`; attach the root part's root body with prefix `<instance>.`; add a free joint `<instance>.free`.
- Others: frame on the target body at mount pose ∘ offset (compose: `pos = mpos + R(mquat)·opos`, `quat = mquat·oquat`).
- Mass: a body with `com` uses explicit inertial (`mass`, `ipos`, `inertia`, `explicitinertial = True`; geoms `density = 0`); a body with `com` but no `inertia` gets a small sphere-like inertia `0.4·m·r²` with r = 0.05. Otherwise every geom of the body gets `density = mass / volume`, where volume is measured by compiling the standalone part with all densities 1 (`model.body_mass`). A body whose geoms have zero volume and no `com` gets explicit inertial at its origin.
- Geoms: box `size` half extents; cylinder `size = [r, L/2, 0]` turned by `axis` (x: +90° about y; y: −90° about x) composed with `rot`; sphere `[r, 0, 0]`; mesh: `spec.add_mesh(name=<part>_<n>, file=abs path)`, geom `meshname`. `friction` → `[f, 0.01, 0.001]`. `color` → `rgba`. Contact bits per Global Constraints.
- Joints: hinge range degrees → radians; slide meters. `spring` → `stiffness`, `springref` (radians for hinges).
- Couplings: `spec.add_equality(type=mjEQ_JOINT, name1=<inst>.<b>, name2=<inst>.<a>, data=[0, ratio] + [0]*9, solref=[0.002, 1])` (MuJoCo: joint1 = polycoef(joint2)).
- Options: `compiler.degree = False`, `option.timestep = 0.001`, `integrator = implicitfast`, `cone = elliptic`, `impratio = 10`; `[model] timestep` (when given) applies after, in World.
- Compile errors from MuJoCo are re-raised as `PartError("assembling the robot: <mujoco message>")`.
- `robot_body` = `<root instance>.<root part's root body>`.

```python
"""[[part]] entries -> one MuJoCo model (via MjSpec) plus the device bindings their slots and ids describe."""

from __future__ import annotations

import math
import re
from dataclasses import dataclass, field
from pathlib import Path

import mujoco
import numpy as np

from .field import add_field
from .model import Body, Geom, Part, PartError, load_part, quat_from_rpy

NAME_RE = re.compile(r"[A-Za-z0-9_]+$")
PLACEMENT_KEYS = ("name", "stock", "path", "attach", "pos", "rot", "ids")
ROBOT_BITS = {"contype": 2, "conaffinity": 1}
NO_BITS = {"contype": 0, "conaffinity": 0}
GEOM_TYPES = {"box": mujoco.mjtGeom.mjGEOM_BOX, "cylinder": mujoco.mjtGeom.mjGEOM_CYLINDER,
              "sphere": mujoco.mjtGeom.mjGEOM_SPHERE, "mesh": mujoco.mjtGeom.mjGEOM_MESH}
AXIS_TURN = {"z": (0, 0, 0), "x": (0, 90, 0), "y": (-90, 0, 0)}   # cylinder z -> axis


@dataclass
class Instance:
    name: str
    part: Part
    source: str                     # "stock chassis" or the part folder
    attach: str | None
    pos: tuple[float, float, float]
    rot: tuple[float, float, float]
    ids: dict
    where: str


@dataclass
class Built:
    model: mujoco.MjModel
    spec: mujoco.MjSpec
    robot_body: str
    instances: list[Instance]
    bindings: dict[str, list[dict]] = field(default_factory=lambda: {"motor": [], "encoder": [], "gyro": []})
    warnings: list[str] = field(default_factory=list)


def _qmul(p, q) -> np.ndarray:
    out = np.zeros(4)
    mujoco.mju_mulQuat(out, np.asarray(p, float), np.asarray(q, float))
    return out


def _rot(v, q) -> np.ndarray:
    out = np.zeros(3)
    mujoco.mju_rotVecQuat(out, np.asarray(v, float), np.asarray(q, float))
    return out


def _vec3(e: dict, key: str, where: str) -> tuple[float, float, float]:
    v = e.get(key, [0, 0, 0])
    if not (isinstance(v, list) and len(v) == 3 and all(isinstance(x, (int, float)) and not isinstance(x, bool) for x in v)):
        raise PartError(f"{where}: {key} must be a list of 3 numbers, not {v!r}")
    return tuple(float(x) for x in v)


def _instances(cfg: dict, cfg_dir: Path) -> list[Instance]:
    from .stock import build_stock
    entries = cfg.get("part")
    if not entries:
        raise PartError("no [[part]] entries")
    if not isinstance(entries, list) or not all(isinstance(e, dict) for e in entries):
        raise PartError("[[part]] must be an array of tables")
    out: list[Instance] = []
    for i, e in enumerate(entries):
        name = e.get("name")
        where = f"parts[{i}] {name!r}" if isinstance(name, str) else f"parts[{i}]"
        if not isinstance(name, str) or not NAME_RE.match(name):
            raise PartError(f"{where}: name must be letters, digits and _ (it prefixes the part's names), not {name!r}")
        if any(x.name == name for x in out):
            raise PartError(f"{where}: the part name {name!r} is used twice")
        if ("stock" in e) == ("path" in e):
            raise PartError(f"{where}: give exactly one of stock = \"<stock part>\" or path = \"<part folder>\"")
        params = {k: v for k, v in e.items() if k not in PLACEMENT_KEYS}
        if "stock" in e:
            part, source = build_stock(str(e["stock"]), params, where), f"stock {e['stock']}"
        else:
            if params:
                raise PartError(f"{where}: {', '.join(repr(k) for k in params)} isn't a key of a path part "
                                f"(allowed: {', '.join(PLACEMENT_KEYS)})")
            folder = (cfg_dir / str(e["path"])).resolve()
            part, source = load_part(folder), str(folder)
        attach = e.get("attach")
        if attach is not None and not (isinstance(attach, str) and attach.count(".") == 1 and all(attach.split("."))):
            raise PartError(f"{where}: attach must be \"<part>.<mount or body>\", not {attach!r}")
        ids = e.get("ids", {})
        if not isinstance(ids, dict):
            raise PartError(f"{where}: ids must be a table of slot = device, not {ids!r}")
        out.append(Instance(name, part, source, attach, _vec3(e, "pos", where), _vec3(e, "rot", where), ids, where))
    roots = [x for x in out if x.attach is None]
    if len(roots) != 1:
        raise PartError("exactly one part without attach is the robot's root (it gets the free joint); "
                        f"parts without attach: {', '.join(x.name for x in roots) or 'none'}")
    return out


def _order(insts: list[Instance]) -> list[Instance]:
    names = [x.name for x in insts]
    for x in insts:
        if x.attach is not None:
            target = x.attach.split(".")[0]
            if target not in names:
                raise PartError(f"{x.where}: attach {x.attach!r}: no part {target!r}; parts: {', '.join(names)}")
    placed: list[Instance] = [x for x in insts if x.attach is None]
    rest = [x for x in insts if x.attach is not None]
    while rest:
        ready = [x for x in rest if x.attach.split(".")[0] in {p.name for p in placed}]
        if not ready:
            raise PartError(f"attach cycle: {', '.join(sorted(x.name for x in rest))}")
        placed += ready
        rest = [x for x in rest if x not in ready]
    return placed


def _target_frame(inst: Instance, by_name: dict[str, Instance]) -> tuple[str, np.ndarray, np.ndarray]:
    """(prefixed body name, pos, quat) of the frame `inst` attaches to, before its own offset."""
    tname, local = inst.attach.split(".")
    target = by_name[tname].part
    for m in target.mounts:
        if m.name == local:
            return f"{tname}.{m.body}", np.array(m.pos), np.array(quat_from_rpy(m.rot))
    if any(b.name == local for b in target.bodies):
        return f"{tname}.{local}", np.zeros(3), np.array([1.0, 0, 0, 0])
    raise PartError(f"{inst.where}: attach {inst.attach!r}: no mount or body {local!r} on {tname!r}; "
                    f"mounts: {', '.join(m.name for m in target.mounts) or 'none'}; "
                    f"bodies: {', '.join(b.name for b in target.bodies)}")


def _add_geom(body, g: Geom, part: Part, spec: mujoco.MjSpec, mesh_names: dict) -> object:
    quat = quat_from_rpy(g.rot)
    kw: dict = {"type": GEOM_TYPES[g.shape], "pos": list(g.pos), **(ROBOT_BITS if g.collide else NO_BITS)}
    if g.shape == "box":
        kw["size"] = [s / 2 for s in g.size]
    elif g.shape == "cylinder":
        kw["size"] = [g.size[0], g.size[1] / 2, 0]
        quat = list(_qmul(quat, quat_from_rpy(AXIS_TURN[g.axis])))
    elif g.shape == "sphere":
        kw["size"] = [g.size[0], 0, 0]
    else:
        path = str((part.base_dir / g.size).resolve())
        if path not in mesh_names:
            mesh_names[path] = f"mesh{len(mesh_names)}"
            spec.add_mesh(name=mesh_names[path], file=path)
        kw["meshname"] = mesh_names[path]
    kw["quat"] = list(quat)
    if g.friction is not None:
        kw["friction"] = [g.friction, 0.01, 0.001]
    if g.color is not None:
        kw["rgba"] = list(g.color)
    if g.condim is not None:
        kw["condim"] = g.condim
    if g.solref is not None:
        kw["solref"] = list(g.solref)
    return body.add_geom(**kw)


def _fill(spec: mujoco.MjSpec, part: Part, densities: dict[str, float] | None) -> dict[str, list]:
    """Add the part's bodies under spec.worldbody; returns body name -> its geoms (spec objects)."""
    bodies, geoms, mesh_names = {}, {}, {}
    for b in part.bodies:
        parent = spec.worldbody if b.parent is None else bodies[b.parent]
        sb = parent.add_body(name=b.name, pos=list(b.pos), quat=quat_from_rpy(b.rot))
        bodies[b.name] = sb
        if b.joint is not None:
            j = b.joint
            hinge = j.kind == "hinge"
            kw = {"name": j.name, "axis": list(j.axis), "damping": j.damping, "frictionloss": j.frictionloss,
                  "armature": j.armature,
                  "type": mujoco.mjtJoint.mjJNT_HINGE if hinge else mujoco.mjtJoint.mjJNT_SLIDE}
            if j.range is not None:
                kw["range"] = [math.radians(v) for v in j.range] if hinge else list(j.range)   # autolimits
            if j.spring is not None:
                kw["stiffness"] = j.spring[0]
                kw["springref"] = math.radians(j.spring[1]) if hinge else j.spring[1]
            sb.add_joint(**kw)
        geoms[b.name] = [_add_geom(sb, g, part, spec, mesh_names) for g in b.geoms]
        if b.com is not None:
            sb.mass, sb.ipos, sb.explicitinertial = b.mass, list(b.com), True
            sb.inertia = list(b.inertia) if b.inertia is not None else [0.4 * b.mass * 0.05 ** 2] * 3
            for g in geoms[b.name]:
                g.density = 0
        else:
            for g in geoms[b.name]:
                g.density = 1.0 if densities is None else densities.get(b.name, 0.0)
    return geoms


def part_spec(part: Part) -> mujoco.MjSpec:
    """The part on its own: names unprefixed, each body's mass spread over its geoms by volume."""
    def fresh(densities):
        s = mujoco.MjSpec()
        s.compiler.degree = False
        _fill(s, part, densities)
        return s
    try:
        probe = fresh(None).compile()
    except ValueError as e:
        raise PartError(f"part {part.name!r}: {e}") from None
    densities = {}
    for b in part.bodies:
        if b.com is None:
            vol = float(probe.body_mass[mujoco.mj_name2id(probe, mujoco.mjtObj.mjOBJ_BODY, b.name)])
            densities[b.name] = b.mass / vol if vol > 0 else 0.0
    s = fresh(densities)
    for b in part.bodies:   # no geometry volume: the whole mass at the body origin
        if b.com is None and densities[b.name] == 0.0:
            sb = s.body(b.name)
            sb.mass, sb.ipos, sb.explicitinertial = b.mass, [0, 0, 0], True
            sb.inertia = [0.4 * b.mass * 0.05 ** 2] * 3
    return s


def assemble(cfg: dict, cfg_dir: Path) -> Built:
    insts = _order(_instances(cfg, cfg_dir))
    by_name = {x.name: x for x in insts}
    spec = mujoco.MjSpec()
    spec.compiler.degree = False
    spec.option.timestep = 0.001
    spec.option.integrator = mujoco.mjtIntegrator.mjINT_IMPLICITFAST
    spec.option.cone = mujoco.mjtCone.mjCONE_ELLIPTIC
    spec.option.impratio = 10
    field_cfg = cfg.get("field", {})
    if not isinstance(field_cfg, dict):
        raise PartError("[field] must be a table")
    add_field(spec, field_cfg)

    pose = cfg.get("robot", {}).get("start_pose") or [0.0, 0.0, 0.0]
    root = insts[0]
    for inst in insts:
        child = part_spec(inst.part)
        root_body = child.body(inst.part.bodies[0].name)
        oq = np.array(quat_from_rpy(inst.rot))
        if inst is root:
            q = quat_from_rpy([0, 0, float(pose[2])])
            frame = spec.worldbody.add_frame(pos=[float(pose[0]), float(pose[1]), 0.0], quat=list(_qmul(q, oq)))
            attached = frame.attach_body(root_body, f"{inst.name}.", "")
            attached.pos = [a + b for a, b in zip(attached.pos, inst.pos)]
            attached.add_freejoint(name=f"{inst.name}.free")
        else:
            body_name, mpos, mquat = _target_frame(inst, by_name)
            pos = mpos + _rot(inst.pos, mquat)
            frame = spec.body(body_name).add_frame(pos=list(pos), quat=list(_qmul(mquat, oq)))
            frame.attach_body(root_body, f"{inst.name}.", "")
        for cp in inst.part.couplings:
            a, b = (f"{inst.name}.{j}" for j in cp.joints)
            spec.add_equality(type=mujoco.mjtEq.mjEQ_JOINT, name1=b, name2=a,
```

```python
"""A part instance's device slots plus its `ids` table -> binding config dicts (today's [[motor]] etc. keys)."""

from __future__ import annotations

from .model import PartError

SHORT = {"TalonFX": ("motor", "ctre"), "CANcoder": ("encoder", "ctre"), "Pigeon2": ("gyro", "ctre"),
         "PWM": ("motor", "pwm"), "DIO": ("encoder", "channel_a")}
PART_KEYS = ("joint", "body", "motor", "count", "gear_ratio", "ratio", "name", "efficiency")


def _device(kind: str, slot: str, value, where: str) -> dict:
    if isinstance(value, str):
        k, sep, n = value.partition(":")
        if not sep or not n.isdigit():
            raise PartError(f"{where}: ids: {slot} = {value!r}: expected \"<Kind>:<number>\", e.g. \"TalonFX:3\"")
        if k not in SHORT:
            raise PartError(f"{where}: ids: {slot} = {value!r}: Kind one of {', '.join(SHORT)} "
                            "(other devices take a table of binding keys, e.g. { can = \"SPARK MAX[3]\" })")
        want, key = SHORT[k]
        if want != kind:
            raise PartError(f"{where}: ids: slot {slot!r} is a {kind} slot; {value} is a {want}")
        return {key: value if key == "ctre" else int(n)}
    if isinstance(value, dict):
        for k in value:
            if k in PART_KEYS:
                raise PartError(f"{where}: ids: {slot}: {k!r} comes from the part; leave it out")
        return dict(value)
    raise PartError(f"{where}: ids: {slot} must be \"<Kind>:<number>\", a table of binding keys"
                    f"{' or a list of them' if kind == 'motor' else ''}, not {value!r}")


def slot_bindings(inst) -> tuple[dict[str, list[dict]], list[str]]:
    part, n, where = inst.part, inst.name, inst.where
    kinds = part.slot_kinds()
    for slot in inst.ids:
        if slot not in kinds:
            raise PartError(f"{where}: ids: no slot {slot!r}; the part's slots: {', '.join(kinds) or 'none'}")
    out: dict[str, list[dict]] = {"motor": [], "encoder": [], "gyro": []}
    warnings: list[str] = []

    def missing(slot: str, verb: str) -> None:
        warnings.append(f"{n}.{slot} has no device ID, so it won't {verb}")

    for s in part.motors:
        value = inst.ids.get(s.slot)
        if value is None:
            missing(s.slot, "move")
            continue
        values = value if isinstance(value, list) else [value]
        if isinstance(value, list) and len(value) != s.count:
            raise PartError(f"{where}: ids: slot {s.slot!r} has {s.count} motors: give one ID or a list of {s.count}")
        for i, v in enumerate(values):
            cfg = _device("motor", s.slot, v, where)
            cfg.update(name=f"{n}.{s.slot}" + (f"[{i}]" if isinstance(value, list) else ""),
                       joint=f"{n}.{s.joint}", motor=s.motor, count=1 if isinstance(value, list) else s.count,
                       gear_ratio=s.gearing, efficiency=s.efficiency,
                       invert=s.invert != bool(cfg.get("invert", False)))
            out["motor"].append(cfg)
    for s in part.encoders:
        value = inst.ids.get(s.slot)
        if value is None:
            missing(s.slot, "report")
            continue
        cfg = _device("encoder", s.slot, value, where)
        cfg.update(name=f"{n}.{s.slot}", joint=f"{n}.{s.joint}", ratio=s.ratio,
                   invert=s.invert != bool(cfg.get("invert", False)))
        out["encoder"].append(cfg)
    for s in part.gyros:
        value = inst.ids.get(s.slot)
        if value is None:
            missing(s.slot, "report")
            continue
        cfg = _device("gyro", s.slot, value, where)
        cfg.update(name=f"{n}.{s.slot}", body=f"{n}.{s.body}")
        out["gyro"].append(cfg)
    return out, warnings
```
