# Java + CTRE Phoenix 6 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An unmodified Java robot project using Phoenix 6 (TalonFX/Kraken, CANcoder, Pigeon 2) runs under Scrimmage with real physics. This includes Tuner X–generated swerve code, whose built-in sim thread is neutralized by a Java agent. Anything that still writes sim inputs is detected.

**Architecture:**
- A Gradle init script (`scrimmage/java/scrimmage.init.gradle`) passed as `./gradlew -I … simulateJava`:
  - enables the WebSocket client and disables the GUI and DS extensions
  - appends the lockstep extension
  - adds `-javaagent`
- The agent (`scrimmage/java/agent`, built with ASM by `scrimmage java build`) turns the robot program's calls to Phoenix 6 `*SimState` physics setters into no-ops (it never modifies Phoenix's classes).
- New Python bindings map Phoenix SimDevices (`CANMotor / Talon FX (v6)[N]` etc.) to joints and bodies.
- Sessions force 1× pacing when Phoenix devices are present.
- A safety net flags sim inputs that Scrimmage didn't send.

**Tech Stack:** Python 3.11+ (venv `.venv`), WPILib 2026.2.1 with JDK 17 at `~/wpilib/2026/jdk`, GradleRIO 2026.2.1, Phoenix 6 26.1.2, ASM 9.10.1, MuJoCo.

**Spec:** `docs/superpowers/specs/2026-10-11-java-ctre-design.md`

## Global Constraints

- **Verified facts.** The research below was verified on this machine on 2026-10-11. Treat these as given:
  - The robot JVM started by `./gradlew simulateJava` inherits the `./gradlew` client's environment, even with a warm daemon. The plan therefore uses environment variables only: `HALSIMWS_HOST`, `HALSIMWS_PORT`, `SCRIMMAGE_LOCKSTEP_SO`, `SCRIMMAGE_AGENT_JAR`.
  - GradleRIO's sim tasks are `simulateJavaRelease` / `simulateJavaDebug` (class `JavaSimulationTask extends JavaExec`).
  - GradleRIO overwrites `HALSIM_EXTENSIONS` in a `doFirst`.
  - The HAL extension names are "Sim GUI", "Use Real DriverStation", "Sim Websockets Server", "Sim Websockets Client" and "Sim XRP Client".
  - Wire names and keys: `CANMotor / Talon FX (v6)[N]` (`<motorVoltage`, `>supplyVoltage`), `CANEncoder / Talon FX (v6)[N]/Rotor Sensor` (`>rawPositionInput` rotations, `>velocity` rps), `CANEncoder / CANcoder (v6)[N]` (`>rawPositionInput`, `>velocity`, `>supplyVoltage`), `CANGyro / Pigeon 2 (v6)[N]` (`>rawYawInput` deg, `>pitch`, `>roll`, `>angularVelX/Y/Z` deg/s, `>supplyVoltage`).
  - Rotor raw input is before the Talon's `Inverted` config, and `getPosition()` applies it.
  - `CANcoder.getPosition()` applies `MagnetOffset`. CANcoder raw input is quantized to 1/4096 rev.
- **ASM** is `org.ow2.asm:asm:9.10.1` from `https://repo1.maven.org/maven2/org/ow2/asm/asm/9.10.1/asm-9.10.1.jar`, sha256 `ed825d10ab1399c8c0cb669e688cf0c8c82629b4c8399b58352b68e92ca10fcb`.
- **CTRE licensing.** CTRE's Phoenix6-Examples repo has **no license**. Don't commit CTRE-authored files (`TunerConstants.java`, `CommandSwerveDrivetrain.java`, `Telemetry.java`) to this repo. Tests may download them at run time from the pinned commit `da029fc9676412dc9a24e3e2e3a3e4d6d71d5107`. WPILib template files (BSD) may be copied.
- **Placeholders and environment:**
  - The config placeholder `{scrimmage_java}` expands to the installed `scrimmage/java` directory.
  - `Session`/`serve` set `SCRIMMAGE_LOCKSTEP_SO` and `SCRIMMAGE_AGENT_JAR` in the robot program's environment when those artifacts exist.
- **Phoenix runs on the wall clock.** Any Phoenix device present means 1× pacing, with the reason reported.
- **Java tests** are marked `@pytest.mark.java`. They skip only when `SCRIMMAGE_SKIP_JAVA=1`.
- **Commands.** Use `.venv/bin/python`. `JAVA_HOME=~/wpilib/2026/jdk` for javac and jar. The network is available for Gradle and Maven.
- **Commits** end with a `Co-Authored-By:` trailer naming the model that wrote them.

## Review Focus

1. **A team's `build.gradle` already enables the GUI or sets `wpi.sim.envVar("HALSIMWS_PORT", …)`.** The init script must still win for the GUI and DS settings. A hard-coded port in the project overriding Scrimmage's port must be detected and reported, not left to hang. Pinned in Task 3 (`test_project_gui_and_port_overrides`).
2. **The agent jar is missing or stale.** Session start must say "run `scrimmage java build`", not time out. Pinned in Task 2 (`test_session_requires_built_agent`).
3. **A real Tuner X project uses a CANivore bus (`new CANBus("canivore")`).** Device names on the wire may include the bus. Bindings must match, or say clearly which names exist. Pinned in Task 7 (`test_tuner_x_project_follows_scrimmage_physics`).
4. **Gradle's first run downloads hundreds of MB, and an offline machine is slow.** `start_timeout` for Java configs must be large enough (default 180 s for gradle commands), and the error must show the Gradle output. Pinned in Task 3.
5. **Echoes of Scrimmage's own writes must not look like foreign writes.** That includes the CANcoder's 1/4096 quantization and in-flight values. Pinned in Task 5 (`test_own_echoes_are_not_foreign`).

```python
"""Java-side tooling: find the WPILib JDK, build the sim-write guard agent, and locate the Gradle init script."""

from __future__ import annotations

import glob
import hashlib
import os
import shutil
import subprocess
import tempfile
import urllib.request
from pathlib import Path

JAVA_DIR = Path(__file__).resolve().parent / "java"
WPILIB_GLOB = str(Path.home() / "wpilib" / "*" / "jdk")
ASM_VERSION = "9.10.1"
ASM_URL = f"https://repo1.maven.org/maven2/org/ow2/asm/asm/{ASM_VERSION}/asm-{ASM_VERSION}.jar"
ASM_SHA256 = "ed825d10ab1399c8c0cb669e688cf0c8c82629b4c8399b58352b68e92ca10fcb"


class JavaToolError(RuntimeError):
    pass


def _cache_dir() -> Path:
    base = os.environ.get("SCRIMMAGE_CACHE")
    d = Path(base) if base else Path.home() / ".cache" / "scrimmage" / "java"
    d.mkdir(parents=True, exist_ok=True)
    return d


def agent_jar_path() -> Path:
    return _cache_dir() / "scrimmage-agent.jar"


def asm_jar_path() -> Path:
    return _cache_dir() / f"asm-{ASM_VERSION}.jar"


def init_script_path() -> Path:
    return JAVA_DIR / "scrimmage.init.gradle"


def _is_jdk(p: Path) -> bool:
    return all((p / "bin" / t).exists() for t in ("java", "javac", "jar"))


def find_jdk() -> Path:
    tried = []
    home = os.environ.get("JAVA_HOME")
    if home:
        tried.append(f"JAVA_HOME={home}")
        if _is_jdk(Path(home)):
            return Path(home)
    for cand in sorted(glob.glob(WPILIB_GLOB), reverse=True):  # newest WPILib year first
        tried.append(cand)
        if _is_jdk(Path(cand)):
            return Path(cand)
    tried.append(WPILIB_GLOB)
    raise JavaToolError("no JDK found (looked at: " + ", ".join(tried) + "). Install WPILib "
                        "(https://docs.wpilib.org) or set JAVA_HOME to a JDK 17.")


def _fetch_asm() -> Path:
    dest = asm_jar_path()
    if dest.exists() and hashlib.sha256(dest.read_bytes()).hexdigest() == ASM_SHA256:
        return dest
    with urllib.request.urlopen(ASM_URL, timeout=60) as r:
        data = r.read()
    digest = hashlib.sha256(data).hexdigest()
    if digest != ASM_SHA256:
        raise JavaToolError(f"downloaded ASM has sha256 {digest}, expected {ASM_SHA256}")
    dest.write_bytes(data)
    return dest


def build_agent(jdk: Path | None = None) -> Path:
    """Compile the agent against ASM and write the jar (with a Class-Path to ASM beside it) to the cache."""
    jdk = jdk or find_jdk()
    asm = _fetch_asm()
    src = sorted((JAVA_DIR / "agent" / "src").rglob("*.java"))
    with tempfile.TemporaryDirectory() as tmp:
        classes = Path(tmp) / "classes"
        classes.mkdir()
        _run([str(jdk / "bin" / "javac"), "--release", "17", "-cp", str(asm), "-d", str(classes), *map(str, src)])
        mf = Path(tmp) / "MANIFEST.MF"
        mf.write_text(f"Premain-Class: scrimmage.agent.ScrimmageAgent\nClass-Path: {asm.name}\n")
        out = agent_jar_path()
        _run([str(jdk / "bin" / "jar"), "cfm", str(out), str(mf), "-C", str(classes), "."])
    return out


def _run(cmd: list[str]) -> None:
    r = subprocess.run(cmd, capture_output=True, text=True)
    if r.returncode != 0:
        raise JavaToolError(f"{Path(cmd[0]).name} failed:\n{r.stdout}{r.stderr}")
```

```groovy
// scrimmage Gradle init script. scrimmage runs:   ./gradlew -I <this file> simulateJava
// It changes nothing in the project's files. For every project using GradleRIO it:
//   - loads only the HALSim WebSocket client (sim GUI, DS socket, WS server, XRP off): scrimmage is the DS
//   - appends the scrimmage_lockstep HALSim extension (SCRIMMAGE_LOCKSTEP_SO) to HALSIM_EXTENSIONS
//   - loads the sim-write guard agent (SCRIMMAGE_AGENT_JAR) so robot-side sim models can't fight the physics
// HALSIMWS_HOST/HALSIMWS_PORT reach the robot JVM through the ./gradlew environment.
def lockstepSo = System.getenv("SCRIMMAGE_LOCKSTEP_SO")
def agentJar = System.getenv("SCRIMMAGE_AGENT_JAR")
final String WS_CLIENT = "Sim Websockets Client"
final List<String> SIM_TASKS = ["simulateJavaRelease", "simulateJavaDebug"]

allprojects { p ->
    p.plugins.withId("edu.wpi.first.GradleRIO") {
        p.afterEvaluate {
            def sim = p.extensions.getByName("wpi").sim
            if (sim.halExtensions.findByName(WS_CLIENT) == null) {
                sim.addWebsocketsClient()               // addX() throws if that name already exists
            }
            sim.halExtensions.all { it.defaultEnabled.set(it.name == WS_CLIENT) }
            def projectPort = sim.environment.get("HALSIMWS_PORT")
            if (projectPort != null && projectPort != System.getenv("HALSIMWS_PORT")) {
                println "scrimmage: WARNING this project's build.gradle sets HALSIMWS_PORT=${projectPort}, " +
                        "which overrides scrimmage's port ${System.getenv('HALSIMWS_PORT')}; remove that line " +
                        "(wpi.sim.envVar(\"HALSIMWS_PORT\", ...)) so scrimmage can connect"
            }

            def simTasks = p.tasks.matching { it.name in SIM_TASKS }
            simTasks.configureEach { t ->
                if (agentJar && new File(agentJar).exists()) t.jvmArgs("-javaagent:" + agentJar)
            }
            if (lockstepSo) {
                // GradleRIO's doFirst overwrites HALSIM_EXTENSIONS; insert ours right before the exec action.
                p.gradle.taskGraph.whenReady { graph ->
                    graph.allTasks.findAll { it.project == p && it.name in SIM_TASKS }.each { t ->
                        t.actions.add(t.actions.size() - 1, { Task task ->
                            def cur = task.environment["HALSIM_EXTENSIONS"]
                            task.environment("HALSIM_EXTENSIONS", cur ? cur + File.pathSeparator + lockstepSo : lockstepSo)
                        } as Action<Task>)
                    }
                }
            }
        }
    }
}
```

Two details to check:
- The `sim.environment` access for the port warning. GradleRIO's sim extension stores its envVars in a map, `getEnvironment()` (see the research note, "`wpi.sim.envVar(...)` in a project's build.gradle wins").
